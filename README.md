# Ummid — GitHub Pages ready

1. ZIP ko Extract All karo.
2. Extracted files GitHub repository ke main level par upload karo. Koi inner folder upload karne ki zaroorat nahi. index.html, style.css, config.js, app.js, three.min.js aur photos ek hi level par hone chahiye.
3. Commit changes karo.
4. Repository Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. Deployment ke baad Pages section mein live link milega.
